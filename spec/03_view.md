# 画面・UI仕様

## 1. 画面一覧と遷移

| 画面 | パス | 説明 |
|---|---|---|
| ログイン | `/login` | Googleでログインする。 |
| アクセス権限エラー | `/no_access` | 利用を許可されていないアカウントでログインしたときに表示する。 |
| 在庫一覧（タブ1） | `/stock` | アイテムをカテゴリ別に表示する。ログイン後の最初の画面。 |
| 買い物リスト（タブ2） | `/shopping_list` | 残りわずか・切れてるのアイテムを表示する。 |
| 設定（タブ3） | `/settings` | 表示名・カテゴリ管理・改善意見・ユーザー管理（開発者用）・ログアウト。 |
| カテゴリ管理 | `/settings/categories` | カテゴリの追加・名前変更・並べ替え・削除。 |
| 改善意見を送る | `/settings/feedback` | 改善意見を送る。自分が送った意見と対応状況の一覧。 |
| 改善意見の一覧（開発者用） | `/feedback` | すべての改善意見の一覧と、対応状況・メモの管理。下部のタブには出さない独立したページ。 |
| ユーザー管理（開発者用） | `/users` | 追加の依頼の承認・却下と、利用を許可されたアカウントの一覧。下部のタブには出さない独立したページ。 |

- アイテム追加・編集は、画面ではなくモーダル（スマホは下から出るシート、PC はダイアログ）で開く。
- 未ログインの状態でログイン画面以外を開いた場合は、ログイン画面へ移動する。ログイン後は、最初に開こうとした画面へ移動する。
- ログイン済みの状態でログイン画面を開いた場合は、在庫一覧へ移動する。
- タブ1〜3 は画面下部のタブ（PC では画面左のナビゲーション）で切り替える。買い物リストのタブには、リストに出ている件数をバッジで表示する。

## 2. 共通の表示

### 更新者・更新日時

- 「〇〇さん・5分前」の形で表示する（〇〇は表示名）。
- 日時の表し方: 1分未満「たった今」/ 1時間未満「N分前」/ 24時間未満「N時間前」/ 前日「昨日」/ それより前「M月D日」/ 前年以前「YYYY年M月D日」。

### 元に戻す（SnackBar）

- ステータス変更・購入完了の直後に、画面下部に「元に戻す」ボタン付きのメッセージを 5 秒間表示する。
- 「元に戻す」を押すと、操作前の状態（ステータス・担当・カゴ済み）に戻す。
- 元に戻すまでの間にほかの人が同じアイテムを変更していた場合は、元に戻さず「ほかの人が変更したため戻せませんでした」と表示する。

### 削除の確認

- アイテム・カテゴリの削除は、確認ダイアログで「削除」を押したときだけ行う。削除は元に戻せない。

### オフライン表示

- オフライン中は、画面上部に「オフラインです。変更は接続が戻ると反映されます」と表示する。

### 入力チェック

| 項目 | ルール | エラー表示 |
|---|---|---|
| アイテム名 | 必須・1〜50文字・ほかのアイテムと同じ名前は不可 | 「同じ名前のアイテムがすでにあります（カテゴリ: 〇〇）」 |
| メモ | 0〜200文字 | |
| カテゴリ名 | 必須・1〜20文字・ほかのカテゴリと同じ名前は不可 | 「同じ名前のカテゴリがすでにあります」 |
| 表示名 | 必須・1〜20文字 | |

- 前後の空白は取り除いてからチェック・保存する。
- 同じ名前かどうかの判定方法は [データ構造](02_data.md) の「名前の重複チェック」に従う。

## 3. ログイン画面（`/login`）

- アプリのアイコン（ホーム画面のアイコンと同じ絵）、アプリ名「おうちストック」、「Googleでログイン」ボタンを表示する。
- ログインに成功したら、利用を許可された家族のアカウントかを確認する。
  - 許可されている: 在庫一覧（または最初に開こうとした画面）へ移動する。
  - 許可されていない: アクセス権限エラー画面へ移動する。
- ログイン中は、ボタンを押せない状態にして読み込み中の表示をする。
- ログインに失敗した場合（キャンセル・通信エラーなど）は、画面にエラーメッセージを表示し、そのままログイン画面に留まる。

## 4. アクセス権限エラー画面（`/no_access`）

- 「アクセス権限がありません」と、ログインしようとしたメールアドレスを表示する。
- 管理者に追加を依頼できるよう、この画面ではログインしたままにする（自動ではサインアウトしない）。
- **まだ依頼していないとき**: 「管理者に追加を依頼する」ボタンを表示する。押すと追加の依頼を作り、「管理者に依頼しました」と表示する。失敗したら「依頼できませんでした。通信状態を確認してください」と表示する。
- **依頼済みのとき**: 「管理者に追加を依頼済みです。承認されたら『もう一度確認する』を押してください。」と、「もう一度確認する」ボタンを表示する。
  - 「もう一度確認する」を押すと、利用を許可されたかを確認し直す。承認されていれば在庫一覧へ移動する。まだなら、この画面のまま。
  - 依頼が却下されていた場合は、もう一度「管理者に追加を依頼する」ボタンが表示される。
- 依頼済みかどうかを確認している間は、読み込み中の表示をする。
- 「別のアカウントでログイン」ボタンで、サインアウトしてログイン画面に戻る。
- この画面のままアプリを閉じた場合はログインしたままなので、次に開いたときもこの画面になる（承認されていれば在庫一覧が開く）。

## 5. 在庫一覧画面（`/stock`）

### 画面上部

- **検索バー**: アイテム名とメモを部分一致で検索する。英字の大文字・小文字、全角・半角、ひらがな・カタカナは区別しない。入力に合わせてすぐに絞り込む。
- **カテゴリフィルター**: 「すべて」と各カテゴリのチップを横に並べる。1 つだけ選べる（初期値は「すべて」）。
- 検索とカテゴリフィルターは同時に使える（両方の条件に合うものを表示する）。
- **凡例**: 検索バーとカテゴリフィルターの下に、ステータスのアイコンと名前（十分 / 残りわずか / 切れてる）を並べ、それぞれの横に全アイテムの件数を表示する。アイテムカードではステータスをアイコンだけで表すため、ここで意味を示す。
- **すべて開く / すべて閉じる**: 画面上部のボタンで、すべてのカテゴリをまとめて開く・閉じる（すべて閉じているときは「すべて開く」、それ以外は「すべて閉じる」）。

### 一覧

- カテゴリごとにセクションを分けて表示する。セクションの並び順はカテゴリの `order` の順。
- セクションの見出しにはカテゴリ名と件数を表示する。アイテムが 0 件のカテゴリは、検索・絞り込み中は表示しない。
- **カテゴリの表示・非表示**: 見出しを押すと、そのカテゴリのアイテムを閉じる（隠す）・開く。
  - 閉じたカテゴリは見出しだけを表示し、見出しの横に「切れてる」「残りわずか」の件数をアイコン付きで表示する（0 件のものは出さない）。
  - 開閉の状態は自分の画面にだけ反映され、ほかの家族の画面は変わらない。別の端末でも同じ状態になる（保存先は [データ構造](02_data.md) の `hiddenCategories`）。保存に失敗した場合は元の状態に戻し、エラーを表示する。
  - 検索・絞り込み中は、閉じているカテゴリも開いて表示する（見出しを押しても開閉しない）。
  - 並べ替えモードでは、すべてのカテゴリを開いて表示する。
- セクション内のアイテムは、**自分の並び順** で並べる（未設定のアイテムは末尾に追加した順。詳しくは [データ構造](02_data.md) の `itemOrder`）。ステータスが変わっても並び順は変えない（タップした直後に位置が動いて誤操作するのを防ぐため）。
- 検索・絞り込みの結果が 0 件のときは「該当するアイテムがありません」と表示する。
- アイテムが 1 件もないときは「右下の＋ボタンからアイテムを追加してください」と表示する。

### アイテムカード

1 画面に多くのアイテムが入るよう、1 件を横 1 行のコンパクトなカードにする。

- 左端: ステータスの色の帯
- アイテム名（1 行。長い場合は省略する）
- メモ（あれば 1 行で表示し、長い場合は省略する）
- 更新者・更新日時（例: 「お母さん・2時間前」）
- 担当・カゴ済みの状態があれば表示する（例: 「🛒 お父さんが買う予定」「✅ お父さんがカゴに入れました」）
- **ステータス切替**（右側）: 「十分 / 残りわずか / 切れてる」の 3 つの **アイコンだけ** のボタン。名前は表示せず、意味は画面上部の凡例で示す（長押し・マウスを乗せると名前を表示する）。選んでいるものはステータスの色で、それ以外は薄い灰色で表示する。押した時点で保存する。
- 「︙」メニュー（右端）: 「編集」「削除」
  - 編集: アイテム追加・編集モーダルを開く。
  - 削除: 確認ダイアログ「『〇〇』を削除しますか？」を出し、「削除」で削除する。

### ステータス変更時の動き

- 変更後に SnackBar「『〇〇』を「切れてる」にしました [元に戻す]」を表示する。
- 「十分」に変更した場合は、担当・カゴ済みも解除する。担当者がほかの人だった場合は、変更前に確認ダイアログ「お父さんが買う予定です。『十分』にしますか？」を出す。

### ステータスのアイコン

| ステータス | アイコン | 色 |
|---|---|---|
| 十分 | ✔（丸にチェック） | 緑 |
| 残りわずか | ⏳（砂時計） | 黄 |
| 切れてる | ✖（丸にバツ） | 赤 |

- 色だけでなく形でも見分けられるようにする。在庫一覧・買い物リスト・アイテム追加・編集モーダルで同じアイコンを使う。

### 右下

- ＋ボタン: アイテム追加モーダルを開く（カテゴリフィルターで選んでいるカテゴリを初期値にする）。

### 並べ替えモード

- 画面上部の「並べ替え」ボタン（↕ アイコン）で並べ替えモードに切り替える。普段の画面ではドラッグで並べ替えできない（ステータス変更などの誤操作を防ぐため）。
- 並べ替えモード中の表示:
  - 画面上部に「並べ替え中」と「完了」ボタンを表示する。
  - 各カードはアイテム名だけの小さな行にし、右端に並べ替え用のつまみ（≡）を表示する。ステータス切替・︙メニュー・メモは表示しない。
  - 検索バー・カテゴリフィルター・＋ボタンは使えない（検索・絞り込み中に「並べ替え」を押した場合は、検索・絞り込みを解除してから並べ替えモードにする）。
- つまみをドラッグして、**同じカテゴリの中で** 並べ替える。ほかのカテゴリへは移動できない（カテゴリの変更は編集モーダルで行う）。
- 指を離した時点で、そのカテゴリの並び順を保存する。保存に失敗した場合は元の並びに戻し、エラーを表示する。
- 並べ替えた結果は自分の画面にだけ反映され、ほかの家族の並びは変わらない。
- 「完了」で通常の表示に戻る。タブを切り替えた場合も通常の表示に戻る。
- 並べ替えモード中に、ほかの家族がアイテムを追加・削除・カテゴリ変更した場合は、すぐに一覧に反映する（追加されたものは末尾に出る）。

## 6. アイテム追加・編集モーダル

| 項目 | 入力方法 | 初期値（追加時） |
|---|---|---|
| アイテム名 | テキスト入力 | 空 |
| カテゴリ | 選択リスト。末尾に「＋ カテゴリ追加」があり、その場で新しいカテゴリを作れる（作ったカテゴリが選ばれた状態になる） | 在庫一覧で絞り込み中のカテゴリ。なければ「その他」 |
| ステータス | SegmentedButton（アイコンと名前） | 「十分」（買い物リストから開いた場合は「切れてる」） |
| メモ | 複数行のテキスト入力 | 空 |

- 「保存」「キャンセル」ボタンを置く。入力チェックに合わない場合は保存できず、項目の下にエラーを表示する。
- アイテム名を入力している途中でも、同じ名前のアイテムがあれば、その場でエラーを表示する。
- 編集時は、モーダル上部に更新者・更新日時を表示する。
- 編集中にほかの人がそのアイテムを削除した場合は、「このアイテムは削除されました」と表示して閉じる。

## 7. 買い物リスト画面（`/shopping_list`）

### 一覧

- ステータスが `low`（残りわずか）または `empty`（切れてる）のアイテムを自動で集めて表示する。
- **切れてる** と **残りわずか** でセクションを分ける（切れてるが上）。見出しにはステータスのアイコンを付ける。
- セクション内は、カテゴリの `order` の順 → 同じカテゴリ内は **自分の並び順**（在庫一覧と同じ）で並べる。買い物リストの画面では並べ替えできない（在庫一覧の並べ替えモードで設定する）。
- リストが 0 件のときは「買う必要のあるものはありません 🎉」と表示する。

### アイテム行

- チェックボックス（カゴ済み）
- アイテム名
- メモ（あれば全文を表示する。買うときに必要な情報のため省略しない）
- カテゴリ名（小さく表示）
- 更新者・更新日時（例: 「お母さん・昨日 切れてるに変更」）
- 担当の状態と操作ボタン（下表）

| 状態 | 表示 | ボタン |
|---|---|---|
| 未担当 | なし | 「買います」 |
| 自分が担当中 | 「🛒 あなたが買う予定」 | 「やめる」 |
| ほかの人が担当中 | 「🛒 お父さんが買う予定」 | 「代わりに買う」 |
| 自分がカゴ済み | 「✅ カゴに入れました」 | なし（チェックを外すと担当中に戻る） |
| ほかの人がカゴ済み | 「✅ お父さんがカゴに入れました」 | なし（チェックボックスも押せない） |

- 担当・カゴ済みにしてから 24 時間以上たっている場合は、「（1日以上前）」を添えて薄く表示する。
- ほかの人がカゴ済みにしている行は、薄く表示してリストの下の方（セクションの末尾）に置く。

### 担当宣言・カゴ済みの操作

- **「買います」**: 自分を担当者にする。
- **「やめる」**: 担当を解除する。
- **「代わりに買う」**: 確認ダイアログ「お父さんが買う予定です。代わりに買いますか？」を出し、「はい」で自分を担当者にする。
- **チェックを入れる**: カゴ済みにする。未担当だった場合は、自分が担当者になる。ほかの人が担当中だった場合は、「代わりに買う」と同じ確認ダイアログを出す。
- **チェックを外す**: 自分の担当中に戻す。
- ほぼ同時にほかの人が先に担当・カゴ済みにしていた場合は、操作を取り消して「すでにお父さんが担当しています」と表示する。

### 購入完了

- 画面下部に「購入完了（N件）」ボタンを固定表示する。N は自分がカゴ済みにした件数。0 件のときは押せない。
- 押すと、自分がカゴ済みにしたアイテムをまとめて「十分」にし、担当・カゴ済みを解除する（＝買い物リストから消える）。ほかの人がカゴ済みにしたアイテムは対象にしない。
- 実行後に SnackBar「N件を購入完了にしました [元に戻す]」を表示する。

### 右下

- ＋ボタン: アイテム追加モーダルを開く（ステータスの初期値は「切れてる」）。思いついたものをその場で買い物リストに追加するため。

## 8. 設定画面（`/settings`）

- **表示名**: 現在の表示名を表示し、タップで変更する（入力ダイアログ）。変更すると、これ以降の更新者・担当者の表示に使われる。
- **カテゴリ管理**: カテゴリ管理画面へ移動する。
- **改善意見を送る**: 改善意見を送る画面へ移動する。
- **改善意見の一覧（開発者用）**: 開発者のときだけ表示し、改善意見の一覧ページへ移動する。
- **ユーザー管理（開発者用）**: 開発者のときだけ表示し、ユーザー管理ページへ移動する。
- **ログアウト**: 確認ダイアログ「ログアウトしますか？」を出し、「ログアウト」でログイン画面に戻る。
- ログイン中の Google アカウントのメールアドレスを表示する。
- アプリのバージョンを表示する。

## 9. カテゴリ管理画面（`/settings/categories`）

- カテゴリを `order` の順に一覧表示する。各行に、カテゴリ名と所属アイテム数を表示する。
- **追加**: 右下の＋ボタンから、名前を入力して追加する。「その他」のすぐ上（一番下）に追加される。
- **名前変更**: 行をタップして、名前を入力し直す。
- **並べ替え**: 行の右端のつまみをドラッグして並べ替える。「その他」は常に一番下で、動かせない。
- **削除**: 行の「︙」メニューから削除する。
  - 確認ダイアログ「『〇〇』を削除しますか？ このカテゴリのアイテム N 件は『その他』に移動します」を出し、「削除」で削除する。
  - 「その他」は削除できない（メニューに「削除」を出さない）。

## 10. 改善意見を送る画面（`/settings/feedback`）

### 送信フォーム

| 項目 | 入力方法 | 初期値 |
|---|---|---|
| 種類 | 「不具合 / 要望 / その他」の SegmentedButton | 要望 |
| 本文 | 複数行のテキスト入力（1〜1000文字、文字数カウンター付き） | 空 |

- 説明文「使ってみて気になったこと・こうなったら嬉しいことを送ってください。開発者だけが読みます。」を表示する。
- 「送信」ボタンは、本文が空のときは押せない。送信中は押せない状態にして読み込み中の表示をする。
- 送信に成功したら、フォームを空に戻し「送信しました。ありがとうございます」と表示する。失敗したらエラーを表示し、入力内容は残す。
- アプリのバージョン・送った人・日時は自動で記録する（画面には入力欄を出さない）。

### 送った意見

- フォームの下に、自分が送った意見を新しい順に表示する（0 件のときは「まだ送った意見はありません」）。
- 各行: 種類・本文（3 行まで、タップで全文）・送った日時・状態（未対応 / 対応中 / 対応済み / 見送り）・開発者のメモ（あれば）。
- 送った意見の変更・削除はできない。

## 11. 改善意見の一覧（開発者用）（`/feedback`）

- 下部のタブ（PC ではサイドナビ）を出さない独立したページ。画面上部に「戻る」ボタン（在庫一覧へ）を置く。PC の広い画面でも見やすいよう、横幅が広いときは中央に最大 960px の幅で表示する。
- 開発者でないアカウントで開いた場合は、「このページを見る権限がありません」と在庫一覧へ戻るボタンを表示する（一覧は読み込まない）。
- 未ログインで開いた場合はログイン画面へ移動し、ログイン後にこのページへ戻る。

### 一覧

- 状態の絞り込みチップ: 「すべて / 未対応 / 対応中 / 対応済み / 見送り」（初期値は「未対応」）。各チップに件数を表示する。
- 種類の絞り込みチップ: 「すべて / 不具合 / 要望 / その他」（初期値は「すべて」）。
- 新しい順に並べる。0 件のときは「該当する意見はありません」。
- 各カード: 種類・本文（全文）・送った人の表示名・送った日時・アプリのバージョン・状態・メモ。

### 対応状況の管理

- **状態**: カード内のドロップダウンで変更し、選んだ時点で保存する。
- **メモ**: 「メモを編集」で入力ダイアログ（0〜500文字）を開き、保存する。メモは送った本人にも表示されることをダイアログ内に明記する。
- **削除**: カードの「︙」メニューから。確認ダイアログ「この意見を削除しますか？」の後に削除する（元に戻せない）。
- ほかの開発者端末での変更や、新しく送られた意見は、再読み込みなしで反映される。

## 12. ユーザー管理（開発者用）（`/users`）

- 下部のタブ（PC ではサイドナビ）を出さない独立したページ。画面上部に「戻る」ボタン（設定画面へ）を置く。横幅が広いときは中央に最大 960px の幅で表示する。
- 開発者でないアカウントで開いた場合は、「このページを見る権限がありません」と在庫一覧へ戻るボタンを表示する（一覧は読み込まない）。
- 未ログインで開いた場合はログイン画面へ移動し、ログイン後にこのページへ戻る。

### 追加の依頼

- 見出し「追加の依頼（N）」の下に、依頼を古い順に並べる。0 件のときは「依頼はありません」。
- 各カード: メールアドレス・Google アカウントの名前（あれば）・依頼日時と、「却下」「承認」ボタン。
- **承認**: 承認ダイアログで次を決め、「承認」で保存する。保存したら「〇〇 を追加しました」と表示する。依頼は一覧から消え、「現在のユーザー」に加わる。

| 項目 | 入力方法 | 初期値 |
|---|---|---|
| メモ | 1 行のテキスト入力（0〜50文字。誰のアカウントか。例: 父） | 依頼したアカウントの名前 |
| 開発者にする | スイッチ（改善意見の一覧・ユーザー管理を使えるようにする） | オフ |

- **却下**: 確認ダイアログ「〇〇 の依頼を却下しますか？（依頼は削除され、本人はもう一度依頼できます）」の後に依頼を削除する。

### 現在のユーザー

- 見出し「現在のユーザー（N）」の下に、利用を許可されたアカウントを、開発者を先にしてメールアドレス順に並べる。
- 各行: メールアドレス・メモ（あれば）・開発者なら「開発者」の印。
- 一覧の下に「メモ・開発者の変更や、ユーザーの削除は Firebase コンソールから行います。」と表示する（アプリからは変更・削除できない）。
- 新しい依頼や承認の結果は、再読み込みなしで反映される。
