# 概要・機能一覧・非機能要件

## 1. プロジェクト概要

- **アプリ名**: おうちストック（ホーム画面・ブラウザのタブ・ログイン画面に表示する）
- **ターゲットユーザー**: 家族5人（スマホ・PCのWebブラウザから利用）
- **目的**: 日用品の在庫状況（十分/残りわずか/切れてる）をリアルタイムで共有し、買い忘れ・重複買いを防ぐ。
- **インフラ**: Firebase (Spark無料枠: Authentication, Firestore, Hosting)

### 目的を達成するための考え方

| 目的 | 仕組み |
|---|---|
| 買い忘れを防ぐ | 「残りわずか」「切れてる」のアイテムを買い物リストに自動で集める。 |
| 重複買いを防ぐ | 買い物リストで「買います」と宣言した人（担当者）と、カゴに入れた状態を家族全員に共有する。 |
| 在庫情報を信用できるようにする | 誰が・いつ更新したかを表示する。誤操作はすぐ元に戻せる。 |

---

## 2. 用語

| 用語 | 意味 |
|---|---|
| アイテム | 管理する日用品（例: トイレットペーパー）。 |
| カテゴリ | アイテムの分類（例: 水回り、その他）。 |
| ステータス | アイテムの在庫状況。下表の 3 段階。 |
| 買い物リスト | ステータスが「残りわずか」「切れてる」のアイテムを自動で集めた一覧。 |
| 担当者 | 買い物リストのアイテムを「買います」と宣言した人。 |
| カゴ済み | 担当者が店でカゴに入れた（チェックを入れた）状態。 |
| 購入完了 | カゴ済みのアイテムをまとめて「十分」に戻し、買い物リストから消す操作。 |
| 表示名 | アプリ内で表示する家族の名前（例: 「お父さん」）。各自が設定画面で変更できる。 |
| 自分の並び順 | 各自が設定したカテゴリ内のアイテムの並び順。ほかの家族の画面には影響しない。 |
| 改善意見 | 家族がアプリを使って感じた不具合・要望などを、アプリから送ったもの。 |
| 開発者 | アプリの開発・運用を行う家族。改善意見の一覧を見て対応状況を管理できる。 |

### ステータス

| 値 | 表示 | 色 | 買い物リストに出るか |
|---|---|---|---|
| `sufficient` | 十分 | 🟢 緑 | 出ない |
| `low` | 残りわずか | 🟡 黄 | 出る |
| `empty` | 切れてる | 🔴 赤 | 出る |

| No | 機能 | 概要 | 画面 |

| F-01 | ログイン | Googleアカウントでログインする。利用を許可された家族のアカウントだけが使える。 | ログイン |
| F-02 | ログアウト | ログアウトしてログイン画面に戻る。 | 設定 |
| F-03 | 在庫一覧 | アイテムをカテゴリ別に表示する。更新者・更新日時も表示する。 | 在庫一覧 |

| F-06 | アイテム追加・編集・削除 | アイテムを登録・変更・削除する。削除は確認してから行う。 | 在庫一覧・買い物リスト |
| F-07 | 買い物リスト | 「残りわずか」「切れてる」のアイテムを自動で集めて表示する。 | 買い物リスト |

| F-10 | 購入完了 | 自分がカゴ済みにしたアイテムをまとめて「十分」に戻す。直後は元に戻せる。 | 買い物リスト |
| F-11 | カテゴリ管理 | カテゴリの追加・名前変更・並べ替え・削除。 | 設定・アイテム追加/編集 |
| F-12 | 表示名の変更 | 自分の表示名を変更する。 | 設定 |
| F-13 | アイテムの並べ替え | カテゴリ内のアイテムの並び順を、ユーザーごとに手動で設定する。在庫一覧と買い物リストの両方に使われる。 | 在庫一覧 |
| F-14 | 改善意見の送信 | アプリへの改善意見（不具合・要望など）を送る。自分が送った意見の対応状況を確認できる。 | 改善意見を送る |
| F-15 | 改善意見の一覧 | 送られた改善意見を一覧で見て、対応状況とメモを管理する。**開発者だけ** が使える。 | 改善意見の一覧 |

### 権限

- 利用を許可された家族は、全員が同じ権限を持つ（すべてのアイテム・カテゴリを閲覧・追加・編集・削除できる）。
- 例外として、改善意見の一覧（F-15）は **開発者** だけが使える。開発者はアプリの開発・運用を行う家族で、どのアカウントが開発者かの管理方法はリポジトリでは扱わない。
- 改善意見は、送った本人と開発者だけが見られる（ほかの家族の意見は見えない）。

## 4. 非機能要件

### リアルタイム反映

- 家族の誰かが行った変更（ステータス・担当・カゴ済み・アイテム・カテゴリ）は、ほかの家族が開いている画面に、再読み込みなしで数秒以内に反映される。

### 同時操作

- 基本は「後から保存した内容で上書き」とする。
- ただし **担当宣言とカゴ済みチェックは、先に操作した人を優先** する。ほぼ同時に 2 人が操作した場合、後の人には「すでに〇〇さんが担当しています」と知らせ、上書きしない（重複買いを防ぐため）。

### オフライン

- 店内など電波が弱い場所でも使えるようにする。
- オフライン中も、最後に取得した内容を表示でき、ステータス変更・チェックなどの操作もできる。操作内容は接続が戻ったときに自動で反映される。
- オフライン中は画面上部に「オフラインです。変更は接続が戻ると反映されます」と表示する。
- オフライン中の操作は「先に操作した人を優先」の判定ができないため、接続が戻った時点で判定し直す。ほかの人が先に担当していた場合はその人を優先し、知らせる。
- ログインはオンライン時のみ行える。

### PWA

- スマホのホーム画面に追加して、アプリのように全画面で起動できる。

### 対応環境

- スマホ（iOS Safari・Android Chrome）と PC（Chrome・Edge・Safari）の最新版。
- 画面幅に合わせてレイアウトを調整する（スマホは 1 列、PC は横幅を広く使う）。

### 費用

- Firebase の Spark（無料）プランの範囲で運用する。Cloud Functions は使わない。
