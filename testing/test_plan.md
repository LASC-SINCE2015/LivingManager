## 5. 実機確認（手作業）

スマホ（iOS Safari / Android Chrome）で確認する。「2 人」とある項目は、許可済みの別アカウント、または PC とスマホの 2 台で同時に開いて確認する。

### ログイン

| ID | 手順 | 期待結果 |
|---|---|---|
| MT-01 | 未ログインで公開 URL を開く | ログイン画面が出る |
| MT-02 | 許可済みのアカウントでログインする | 在庫一覧が出る。初回は「水回り」「その他」がある |
| MT-03 | 許可されていないアカウントでログインする | 「アクセス権限がありません」とメールアドレスが出て、自動でサインアウトされる |
| MT-04 | ログインのポップアップを閉じる | 「ログインがキャンセルされました」と出る |
| MT-05 | 設定 → ログアウト | 確認ダイアログの後、ログイン画面に戻る |
| MT-06 | ホーム画面に追加して起動する | 全画面で起動し、ログイン状態が保たれている |

### 在庫一覧・アイテム

| ID | 手順 | 期待結果 |
|---|---|---|
| MT-11 | ＋からアイテムを追加する | 選んだカテゴリのセクションに出る。更新者・「たった今」が出る |
| MT-12 | 既存と同じ名前（カタカナ/ひらがな違いを含む）で追加する | 「同じ名前のアイテムがすでにあります」と出て保存できない |
| MT-13 | 追加画面で「＋ カテゴリ追加」 | 新しいカテゴリが作られ、選ばれた状態になる |

| MT-16 | 削除する | 確認ダイアログの後に消える |
| MT-17 | 2 人: 片方でステータスを変える | もう片方に再読み込みなしで反映される |
