# 0013 LINE で買い物を頼むときは、共有用の URL で LINE を開くだけにする

- 状態: 採用
- 日付: 2026-11-01

## 状況

アプリを開かない家族や、外出中の家族に「〇〇を買ってきて」と頼みたい（仕様 F-18）。家族の連絡は LINE で取っている。買い物リストから頼むものを選んで、LINE で送れるようにしたい。

## 決定

- **`https://line.me/R/share?text=<文面>` を開き、送る相手は LINE の画面で選ぶ。** 文面は「買い物をお願いします。」と、選んだアイテムを 1 行ずつ（メモがあれば（ ）で添えて）並べたもの。
- **頼んでもアプリの担当は変えない。** Firestore には何も書かない。
- 頼むものは買い物リストの選択モードで選ぶ。誰かがカゴに入れたアイテムは選べない。
- 文面の空白は `%20` の形でエンコードする（`+` のまま届かないようにするため）。

## 理由

- LINE の Messaging API などを使うと、公式アカウントの作成やサーバー側の処理（Cloud Functions など）が必要になる。共有用の URL なら、LINE アプリの「送信先を選ぶ」画面がそのまま使え、アプリ側の準備がいらない。
- 誰に送ったか（送信先）はアプリから分からないので、頼んだ相手を担当にすることはできない。自分を担当にする案もあったが、自分は買わないのに「〇〇が買う予定」と表示されて紛らわしいため、担当は変えないことにした（頼まれた人がアプリを開けるなら、その人が「買います」を押す）。

## 影響

- スマホでは LINE アプリが開く。PC では LINE の Web ページが開き、LINE のアプリまたはログインが必要になる。
- ボタンを押した処理の中で開かないとブラウザにポップアップとして止められるため、開く前に `await` しない。
- 頼んだことはアプリに残らない（LINE のトークに残る）。
