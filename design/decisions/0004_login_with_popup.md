# 0004 Google ログインはポップアップ方式にする

- 状態: 採用
- 日付: 2026-10-25

## 状況

Firebase Authentication の Web の Google ログインには、ポップアップ方式（`signInWithPopup`）とリダイレクト方式（`signInWithRedirect`）がある。リダイレクト方式は、ブラウザのサードパーティ Cookie などの制限により、ログイン用のドメインとアプリのドメインが違うと失敗することがある。ポップアップ方式は、ボタンを押した操作から開かないとブロックされることがある。

## 決定

PoC では、すべての環境でポップアップ方式を使う。毎回アカウントを選べるよう `prompt=select_account` を付ける。

## 理由

- ボタンを押した操作から開くので、スマホのブラウザでもブロックされにくい。
- リダイレクト後の結果の受け取りが不要で、実装が単純になる。

## 影響

- ホーム画面に追加した PWA（全画面表示）から開いた場合に、ポップアップがうまく動かない端末がある可能性がある。問題が出たら、スマホではリダイレクト方式に切り替えることを検討する。
- ポップアップを閉じた場合は「ログインがキャンセルされました」と表示する。
