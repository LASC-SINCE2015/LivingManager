# 0008 オフライン判定は Firestore のキャッシュ状態を使う

- 状態: 採用
- 日付: 2026-10-25

## 状況

オフライン中は画面上部に「オフラインです。変更は接続が戻ると反映されます」と表示する（仕様）。オフラインかどうかを知る方法として、ブラウザのネットワーク状態を見る方法と、Firestore とつながっているかを見る方法がある。

## 決定

- Firestore の `items` コレクションを 1 件だけ `snapshots(includeMetadataChanges: true)` で購読し、`metadata.isFromCache`（データがサーバーではなくキャッシュから来ている）を見る（`isOfflineProvider`）。
- 起動直後や一瞬の切断で表示がちらつかないよう、キャッシュからの状態が **3 秒続いたときだけ** オフラインとして表示する。サーバーから受け取ったらすぐに消す。

## 理由

- ユーザーにとって大事なのは「変更が家族に届いているか」であり、それは Firestore とつながっているかで決まる。ブラウザがネットワークにつながっていても、Firestore に届かなければ変更は反映されない。
- 追加のパッケージが要らない（Firestore の機能だけで済む）。
- 1 件だけの購読なので、読み取り回数への影響が小さい。

## 影響

- 判定は Firestore の購読に依存するため、ログインしていないときは判定しない（常にオフライン表示なし）。
- 接続が切れてから表示されるまで、Firestore が切断に気づく時間＋3 秒かかる。
- オフライン中もアプリはキャッシュで表示・操作できるが、トランザクションを使う操作（担当宣言など）は失敗する（[0002](0002_claim_with_transaction.md)）。
